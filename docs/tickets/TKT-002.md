### 3. IMPACTO EN FRONTEND
- **Componentes y Vistas Afectadas**:
  - Definición de especificación y anatomía para los 6 componentes clave:
    1. Sticky Header persistente con Mega-Dropdown de impacto (corrección de 4 enlaces 404).
    2. Hero Rotor Dinámico con máscara gráfica institucional y encuadre inteligente (eliminando banners apilados).
    3. Grid de 4 Pilares de Impacto con fotos representativas, badges oficiales y hover dinámico ("con sal y pimienta").
    4. Sección de Empresas Aliadas / RSE (3 pilares: inversión social, voluntariado corporativo, donación por nómina).
    5. Plantilla Maestra Modular de Programa (16 subpáginas estandarizadas con bloques y toggles).
    6. Plantilla Maestra de Emergencia / Evento Especial (split-screen con contenedor para Givecloud embed).
- **Consumo de API centralizada / Datos tipados**: Especificado el modelo de datos tipados en TypeScript (`ProgramaConfig`, `HeroSlideConfig`, `PilarImpactoConfig`).
- **Manejo de Estado / Caché**: Estado local reactivo para el Hero Rotor (pausa en hover, auto-rotación cada 6 segundos) y control del Sticky Header al superar los 80px de scroll.
