### 3. IMPACTO EN FRONTEND Y DESCRIPCIÓN DEL REQUERIMIENTO
**Diagnóstico del Problema**:
La Lámina 2 del Manual Oficial prohíbe estrictamente el uso de Antonio en minúsculas (caja mixta) o en cursiva (italics). Antonio Bold es una fuente condensada diseñada para titulares mayúsculos de alto impacto. Se detectaron 28 instancias en el código donde se aplica font-display sin la clase uppercase (ej. nombres de directivos, preguntas de FAQ, paquetes de patrocinio).

**Especificaciones Técnicas de Implementación**:

- **frontend/src/index.css**:
  - Agregar regla de blindaje CSS global:
    ```css
    .font-display {
      font-family: var(--font-display);
      text-transform: uppercase;
      font-style: normal !important;
    }
    ```
- **Auditoría de Componentes**:
  - Revisar y agregar `uppercase` en todas las ocurrencias de `font-display` en:
    - `NosotrosEquipoPage.tsx`: Nombres de puestos y directores.
    - `PatronatoPage.tsx`: Nombres de consejeros honorarios.
    - `PreguntasFrecuentesPage.tsx`: Preguntas del acordeón (o migrarlas a `font-heading` / `font-body` si requieren caja mixta para lectura fluida).
    - `TorneoGolfPage.tsx` y `ListaGolfPage.tsx`: Fechas, paquetes de patrocinio y sedes.
    - `GivecloudModal.tsx` y `DonacionPage.tsx`: Botones de montos predefinidos.
- **Cuerpo Editorial**:
  - Asegurar que todo párrafo de descripción use `font-body` (`Palanquin` Regular/Medium) con color `#646567` sobre fondos claros.
